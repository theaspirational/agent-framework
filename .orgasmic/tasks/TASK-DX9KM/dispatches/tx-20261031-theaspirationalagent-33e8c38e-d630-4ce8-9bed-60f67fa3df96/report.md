## Findings

### LOW-A (correctness, diagnostic-only) — `src/mcpl/reply-admission.ts:48`: the structural `mode` predicate is a one-sided false-negative surface for the loss diagnostic

The predicate is now `applied?.mode === 'context-only' && delivery?.mode !== 'context-only'`. `applied` comes only from the module-private ALS store (`inbound-delivery.ts:10,14-16`, written solely at `channel-registry.ts:1983`), so it is trusted. `delivery` is the caller's fourth argument. An internal wrapper that *replaces* the argument with any object carrying `mode: 'context-only'` but `conversational: true` silences the loss line, even though the argument no longer restricts.

Failure scenario: wrapper forwards `{ mode: 'context-only', conversational: true }`; `applied` is still `CONTEXT_ONLY`, so `reply-admission.ts:53` (`applied?.conversational === false || …`) still returns the verdict and preparation is still suppressed — but no diagnostic is emitted, so the dropped-restriction wrapper is invisible to operators. **No permission is created**: the suppression expression is a disjunction over two independent restriction reads, and `delivery` can only ever add a restriction there. This is the intended `truth.forwarded-copy` trade (R4 item 2) and the right trade for the duplicate-constant case; it is worth recording as a diagnostic blind spot rather than treated as fixed. Fix direction (if ever wanted): compare `conversational`/`wake` as well as `mode`, i.e. require full structural equality with `CONTEXT_ONLY`, not just mode.

### LOW-B (design) — `src/mcpl/reply-admission.ts:39,49`: the default `diagnosticConnection = admission.key` makes the throttle window per-transport-epoch, not per-connection, for direct helper callers

`admission.key` is a **fresh frozen object per `RequiredAdmission.bind(epoch)`** (`inbound-admission.ts:124`, and the `transportEpoch: -1` fallback at `:135`). So any caller of `withReplyConsumer` that omits the fourth argument gets a throttle holder that is discarded on every rebind, printing one fresh first line per transport epoch. Fix direction: none required; if the default is ever load-bearing, document that it is epoch-scoped.
